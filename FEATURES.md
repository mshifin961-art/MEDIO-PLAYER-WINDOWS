# Feature Checklist — MEDIO PLAYER Windows Edition

- [x] Independent Windows x64 Kotlin + Compose Multiplatform Desktop project
- [x] Cinematic Dark & Pure AMOLED glassmorphic themes matching Android MEDIO PLAYER
- [x] Sidebar navigation (Home, Music Library, Video Library, Albums, Artists, Folders, Playlists, Recently Played, Favorites, Settings)
- [x] Bottom player bar with artwork, seek bar, play/pause, skip, shuffle, repeat, volume, and queue
- [x] Music playback via LibVLC with queue, shuffle, repeat, and metadata extraction (`jaudiotagger`)
- [x] Video playback via LibVLC with fullscreen, speed (`0.25x`–`2.0x`), aspect ratio, audio tracks, embedded & external subtitles, and resume position
- [x] Local media scanner with watched folders, missing file cleanup, search, and sorting
- [x] Persistent SQLite database with migrations and deduplication
- [x] Persistent disk-cached thumbnails & embedded album artwork
- [x] Playlist management (create, rename, delete, add, remove, reorder)
- [x] Desktop shortcuts (`Space`, `Left/Right`, `Up/Down`, `F`, `M`, `Ctrl+M`, `Esc`), Drag & Drop import, Mini Player, CLI file launch
- [x] Windows x64 distributable & Inno Setup `.exe` installer
